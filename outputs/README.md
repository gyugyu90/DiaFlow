# Diagram Outputs

`create-diagram` saves new Diagram JSON documents in this directory when no output path is given.
Run `npm run dev`, then refresh the local editor home page to open any valid
`*.diagram.json` file placed here.

`npm run build` copies these documents to `dist/diagrams/` for self-hosted viewer embeds. Commit
the Diagram JSON files you want to keep or deploy; this README is only a guide.
